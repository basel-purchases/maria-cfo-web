# Maria CFO Web v0.25 — تحسين العرض، ترقيم الأوردرات والوصفات، وكشوف الموردين

## التثبيت بالترتيب

1. **احتفظ بنسخة احتياطية من قاعدة Supabase والمستودع** قبل أي تحديث.
2. يجب أن تكون ترحيلات قاعدة البيانات حتى `v0.24` منفذة أصلًا. نفذ `database/Maria_CFO_Web_v0.25_Migration.sql` في قاعدة **تجريبية** أولًا ثم جرّب قراءة كشوف الموردين وإعادة رفع كشف الأمين نفسه.
3. بعد نجاح الاختبار على نسخة تجريبية، نفذ SQL v0.25 على قاعدة الإنتاج بعد أخذ نسخة احتياطية جديدة.
4. فك ضغط ZIP وانسخ **محتوياته** إلى مستودع GitHub Pages الحالي. استبدل الملفات المتطابقة، ولا تحذف المستودع الحالي.
5. لا تستبدل ملف `config.js` الحالي أو إعدادات Git/GitHub. الحزمة لا تتضمن تلك الملفات عمدًا.
6. حدّث الموقع تحديثًا قويًا (`Ctrl+Shift+R`) وتأكد أن القائمة تعرض `Web v0.25`.
7. لا داعي لإعادة نشر Supabase Edge Functions `assistant` أو `ocr-space` في هذا الإصدار.

## تفاصيل التحسينات

- **المواد والكميات:** لم نعد نضغط عمود الأزرار إلى حروف عمودية. الجدول أصبح واسعًا مع تمرير أفقي داخله عند اللزوم. يظهر آخر سعر شراء معروف منفصلًا عن سعر تقرير الأمين، مع عمود مستودعات الجرد وكمية كل مستودع وزر يعرض جميع حقول المصدر (التصنيف، الوحدة، الكمية البديلة، الملاحظات، السعر، التوقيت).
- **القوائم المنسدلة:** مظهر RTL موحد، وسهم واضح على اليسار، وحالة تركيز ظاهرة، مع احترام القوائم داخل النماذج والديالوغات.
- **الوجبات والوصفات:** تحميل *18 وجبة في الصفحة* مباشرةً من قاعدة البيانات، مع البحث بالاسم وفلتر التصنيف. تحميل مكونات الوصفات والوحدات عند فتح الوصفة فقط بدل تحميلها مسبقًا أثناء عرض جميع الوجبات.
- **الأوردرات والطلبيات:** *25 أوردرًا في الصفحة* من قاعدة البيانات مباشرةً، مع عداد وترقيم. قائمة المراجعة الخاصة بصور الأوردرات لم تتغير.
- **الأساسيات:** عرض الوحدة، كمية التقرير لكل مستودع، سعر التقرير، الحد الأدنى، ملاحظات الصنف، والتنبيهات. الجدول مقسم إلى 20 عنصرًا في الصفحة.
- **الموردون:** صفحة موحدة تجمع الموردين المحفوظين وكشوف الموردين المستوردة، مع رقم الحساب، الهاتف، جهة الاتصال، الرصيد السابق، المدين الإجمالي، الدائن الإجمالي، الأوراق التجارية غير المحصلة، والرصيد الحالي. فلتر خاص بالأرصدة الموجبة (ديون غير مسددة حسب تقرير الأمين)، مع البحث بالاسم أو رقم الحساب أو الهاتف، ثم فتح حركات كل مورد في نافذة قابلة للترقيم.

## تحديث مهم لحقل الأوراق التجارية

أضاف SQL v0.25 حقل `uncollected_papers_v025` إلى كشوف الموردين، ويحدث دالة `import_ameen_v024` لإيصاله من عمود «رصيد الأوراق التجارية غير المحصلة» في Excel. **البيانات المستوردة قبل v0.25 ستكون قيمة هذا الحقل فيها غير معروفة**، وليست صفرًا مؤكدًا. أعد رفع ملف «كشف حساب زبون.xlsx» نفسه عبر الإدخالات السريعة بعد التحديث مرة واحدة، وسيملأ النظام الحقل الجديد **دون تكرار السندات أو تغيير الدفعات**، حتى إذا كانت بصمة الملف مطابقة لبصمته السابقة.

## محاسبة الديون

المورد الذي يحمل رصيدًا موجبًا في عمود «الرصيد الحالي» في تقرير الأمين يظهر مع تحذير «دين غير مسدد بحسب الأمين». هذه إشارة مرجعية من آخر تقرير متاح وليست إثباتًا لسند مستحق جديد في Maria CFO. لا يتم تسجيل أي حركة في صناديق المطعم أو تسديد أي ذمة بمجرد قراءة التقرير. قد يحتاج المبلغ إلى مراجعة إذا حدثت دفعة بعد تاريخ الكشف.

## الاختبارات والحدود

- اجتازت اختبارات Node المحلية الاختبارات السابقة والجديدة، بما في ذلك ملفات الأمين الثلاثة من العينات المرفوعة، ومنطق منع تكرار الموردين، وتغيير صفحات القوائم.
- فُحص تركيب JavaScript وملفات الحزمة بعد إنشاء ZIP.
- **لم ينفذ SQL على قاعدة Supabase الحية أو على نسخة تجريبية مطابقة.** يجب تجربته أولًا وفق الخطوات أعلاه.
- تعذر تشغيل اختبار واجهة المتصفح محليًا لأن بيئة التنفيذ تمنع فتح خادم HTTP المحلي؛ لذلك لا نجزم بأن المظهر في متصفحك مطابق 100% دون تجربة قبول بعد النشر.
- لا تغيّر v0.25 قواعد نشر الإيرادات أو خصم المخزون أو دفع الرواتب. وظيفة SQL الوحيدة هي الاحتفاظ بالحقل الإضافي من كشف الأمين، مع حفاظ دالة الاستيراد على صلاحيات المالك والمعاملة المحمية.

راجع `docs/TEST_RELEASE_V025_AR.md` لخطوات الاختبار اليدوي.
