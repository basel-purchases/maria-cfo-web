# Maria CFO Web v0.9

هذا الإصدار يركز على جعل تسجيل فاتورة الشراء سريعًا من شاشة واحدة.

## قبل الاختبار
شغّل مرة واحدة في Supabase SQL Editor:

`database/Maria_CFO_Web_v0.9_Migration.sql`

ثم استبدل ملفات المشروع فوق `Maria-CFO-Web-Live` مع الإبقاء على `config.js` الموجود لديك.

## اختبار سريع
1. افتح مسودة فاتورة شراء.
2. اختر السكر.
3. عرّف التحويل: `1 شوال = 30 كيلوغرام`.
4. اختر `شوال`، الكمية `2`، والسعر ثم أضف البند.
5. يجب أن يظهر البند فورًا بدون خطأ.
6. جرّب **+ مادة جديدة** من نفس النافذة، وأدخل مادة غير موجودة.
7. جرّب كتابة اسم مادة موجودة مسبقًا؛ يجب أن يمنع التكرار ويختار الموجودة.
