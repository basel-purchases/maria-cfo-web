# Maria CFO Web v0.3

هذه نسخة تطوير الموقع بعد مراجعة تجربة الاستخدام على v0.2.

## طريقة الاستخدام مع مجلد Maria-CFO-Web-Live

هذه الحزمة مصممة للاستبدال المباشر داخل مجلد المشروع المستنسخ من GitHub.

1. فك ضغط `Maria-CFO-Web-v0.3.zip`.
2. انسخ كل الملفات والمجلدات الناتجة مباشرة إلى داخل `Maria-CFO-Web-Live`.
3. وافق على استبدال الملفات الموجودة.
4. **لا تحذف `config.js` الموجود لديك.** هذه الحزمة لا تحتويه عمدًا لأن إعداد الاتصال ثابت لديك.
5. اختبر محليًا، ثم نفّذ `git status` وCommit/Push عند رضاك عن النتيجة.

## أهم تعديلات v0.3

- صفحة المواد أصبحت: **المواد والكميات والأسعار**.
- الحقل أصبح: **الحد الأدنى للرصيد قبل التنبيه**.
- الكميات تعرض وحدتها بجانب الرقم.
- السعر يعرض بصيغة مثل: `200 SYP / صندوق`.
- المواد مرتبة حسب وقت الإضافة من الأقدم إلى الأحدث.
- نافذة الإضافة والتعديل أبسط وأقل شرحًا.
- زر الرجوع في الجهة المقابلة للعنوان.
- تذييل القائمة يعرض إصدار الموقع فقط.

## ملاحظة مهمة

`config.js` غير موجود في ZIP عمدًا. احتفظ بالنسخة الموجودة في Repository لأنها تحتوي Project URL وPublishable Key.
