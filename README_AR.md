# Maria CFO Web v0.4

هذه الحزمة مصممة للاستبدال المباشر داخل مجلد `Maria-CFO-Web-Live`.

## مهم

الحزمة **لا تحتوي `config.js`** ولا تحتوي مجلد `.git` أو ملف `.gitignore`، لذلك إعداد الاتصال الحالي بـSupabase ومستودع Git لن يتغيرا عند نسخ الملفات.

## قبل اختبار v0.4

شغّل مرة واحدة في Supabase SQL Editor الملف:

`database/Maria_CFO_Web_v0.4_Migration.sql`

المهاجرة تضيف:

- وحدات مطاعم إضافية.
- الحقل `default_discount_percent` للوجبات.

وهي idempotent ويمكن تشغيلها أكثر من مرة بأمان.

## نموذج الوحدات في v0.4

كل مادة لها وحدة مخزون أساسية، ويمكن ربط وحدات أخرى بها:

- بيض: الوحدة الأساسية `قطعة`، ووحدة الشراء `سفط`، مثل 1 سفط = 30 قطعة.
- رز: الوحدة الأساسية `كيلوغرام`، ووحدة الشراء `شوال`، مثل 1 شوال = 25 كغ.
- شاي: الوحدة الأساسية `ظرف`، ووحدة شراء `علبة` ثم `كرتونة` إذا لزم.
- سكر: الوحدة الأساسية `كيلوغرام`، ووحدة شراء `شوال`، ويمكن إضافة وحدة استخدام `ملعقة` من شاشة الوصفة.

قاعدة البيانات تبقى محتفظة بكمية كل وحدة نسبةً إلى وحدة المادة الأساسية، ولذلك المشتريات والوصفات والمخزون تتحدث لغة قياس واحدة داخليًا.
