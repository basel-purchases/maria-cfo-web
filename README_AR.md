# Maria CFO Web — المشروع الكامل (الإصدار الحالي v1.0.25)

نظام إدارة مالي وتشغيلي لمطعم وحفلات، بواجهة عربية RTL مبنية على HTML/CSS/JavaScript وSupabase/PostgreSQL.

**الجديد:** طلبات داخلية غير مخططة للحفلة، ضيافة إضافية بتكلفة فقط، مشتريات خارجية مع مبلغ ربح للوحدة، وفصل تكلفة الشراء عن فاتورة العميل والدفع والتحصيل، وتقرير موحد لتكلفة الحفلة وربحها.

ابدأ بدليل الإصدار: [README_v1.0.25_EVENT_ORDERS_HOSPITALITY_PROFIT_AR.md](README_v1.0.25_EVENT_ORDERS_HOSPITALITY_PROFIT_AR.md).

## التثبيت

1. نسخة احتياطية قابلة للاستعادة واختبار على بيئة تجريبية مطابقة.
2. تحقق من تطبيق الترحيلات السابقة حتى v1.0.24، ثم نفذ `database/Maria-CFO-Web-v1.0.25-Event-Orders-Hospitality-Profit.sql`.
3. نفذ `database/Maria-CFO-Web-v1.0.25-VERIFY-READONLY.sql` واختبارات القبول في `tests/V125_STAGING_ACCEPTANCE_AR.md`.
4. ارفع كامل ملفات ZIP مع إبقاء config.js الحالي، ثم أعد التحميل بقوة وتحقق من Web v1.0.25.

لا يحتوي ZIP على config.js أو بيانات Supabase. لا تشغل ملفات RESET/DANGER التاريخية ولا جميع الترحيلات عشوائيًا.

## الاستخدام

الحفلات ← الحفلة ← «الطلبات الداخلية والخارجية» أو «المشتريات الخارجية والربح». تقرير التكلفة والربح يعرض الأثر في إجماليات الحفلة. الوظائف متاحة أيضًا من شاشة حجوزات الحفلة.

الموردون وإحصائياتهم، الصناديق المستمرة، الموظفون والرواتب، المواد والوصفات والفواتير بقيت موجودة. وثائق v1.0.24 وما قبلها محفوظة كمراجع تاريخية، لا باعتبارها الإصدار الحالي.

## الاختبارات وحدود التسليم

Node: 448 اختبارًا، 441 ناجحًا، 7 متجاوزة، دون إخفاقات. Chromium: 15 سيناريو واجهة ناجحًا ببيانات/API محاكاة. التفاصيل في `qa/v1.0.25/` ودليل الإصدار.

**لم يُنفذ SQL الجديد على PostgreSQL في بيئة الإعداد، ولم يُختبر تكامل Supabase الحي أو يُطبّق عليه شيء.** يجب اختبار الترحيل ومعاملات القبض والدفع على نسخة تجريبية قبل الإنتاج. سجل الطلبات الداخلية الجديد يحتسب التكلفة ماليًا ولا يضيف صرف مخزون تلقائيًا؛ اقرأ حدود المخزون في دليل الإصدار.

تشغيل اختبارات Node: `node --test tests/*.test.mjs`.
