# Maria CFO Web v0.8

نسخة ويب تجريبية تركز على وضوح تجربة الاستخدام ودقة الوصفات والتكاليف.

## أهم ما في v0.8
- تحديث بطاقات الوجبات فور إغلاق نافذة الوصفة حتى عند الإغلاق بزر ×.
- إعادة ترتيب نافذة الوصفة: إضافة المكوّن من الأعلى، والحفظ والإغلاق في الأسفل.
- عرض سعر وحدة كل مكوّن وتكلفته حسب آخر سعر معروف للمادة وتحويل الوحدة.
- عرض إجمالي تكلفة الوصفة الحالية داخل نافذة الوصفة.
- إظهار سعر البيع بعد الخصم الافتراضي وحساب Food Cost المعروض على السعر بعد الخصم.
- تحسين تخطيط نافذة الوصفة على الكمبيوتر والهاتف.

## قاعدة البيانات
لا توجد Migration جديدة خاصة بـ v0.8.
آخر Migration لازمة للوصفات هي:
`database/Maria_CFO_Web_v0.7_Migration.sql`
وإذا كنت قد شغلتها سابقًا بنجاح فلا تعِد تشغيل أي شيء من أجل v0.8.

## التثبيت فوق Maria-CFO-Web-Live
انسخ محتويات ZIP مباشرة فوق مجلد المشروع ووافق على الاستبدال.
الحزمة لا تحتوي `config.js` ولا `.git`.
