# Maria CFO Web v0.13

هذه نسخة اختبار تركز على ثلاثة أجزاء أساسية: **الأوردرات، الصناديق، والمصروفات**، مع إبقاء نظام OCR الخلفي من v0.12.

## طريقة التحديث
1. فك ضغط الحزمة وانسخ محتوياتها مباشرة فوق مجلد `Maria-CFO-Web-Live`.
2. الحزمة لا تحتوي `config.js` ولا ملفات Git.
3. شغّل في Supabase SQL Editor الملف:
   `database/Maria_CFO_Web_v0.13_Migration.sql`
4. افتح Edge Functions → `document-ocr` → Code، واستبدل `index.ts` بالملف الموجود في:
   `supabase/functions/document-ocr/index.ts`
5. Deploy للـFunction.
6. نفّذ `Ctrl + F5` في المتصفح.

## لماذا الصناديق؟
الصندوق ليس إعدادًا شكليًا. هو مكان النقد الفعلي. عند نشر أوردر يدخل الإيراد للصندوق، وعند تسجيل مصروف أو دفعة يخرج المبلغ منه. إذا كان لديك رصيد فعلي عند بدء النظام، استخدم زر **إضافة / سحب رصيد** مرة واحدة لتسجيله.

## اختبار سريع للأوردر
1. أنشئ أوردر واختر صندوق 1.
2. أضف صنفًا بكمية وسعر.
3. تأكد أن السطر ظهر فورًا.
4. اضغط نشر الأوردر.
5. افتح الصناديق وتأكد أن رصيد صندوق 1 زاد بقيمة صافي الأوردر.

## اختبار سريع للمصروف
1. افتح المصروفات وأضف مصروفًا على صندوق 1.
2. اختر المبلغ والعملة والتصنيف واكتب تفاصيل اختيارية.
3. بعد الحفظ يجب أن يظهر المبلغ والصندوق والتصنيف في الجدول.
4. افتح الصناديق وتأكد أن الرصيد انخفض بقيمة المصروف.
