# Maria CFO Web v0.7

إصدار إصلاح مركز على الوصفات وإضافة المكونات.

## قبل الاختبار
شغّل مرة واحدة في Supabase SQL Editor:

`database/Maria_CFO_Web_v0.7_Migration.sql`

ثم استبدل ملفات المشروع فوق مجلد `Maria-CFO-Web-Live` مع الإبقاء على `config.js` الموجود لديك.

## ما تم إصلاحه
- إضافة مكوّن جديد أصبحت إضافة حقيقية فقط، وليست تعديلًا صامتًا لمادة موجودة.
- المواد الموجودة مسبقًا في الوصفة لا تظهر داخل قائمة «إضافة مكوّن»؛ تعديلها يتم من زر «تعديل» في السطر نفسه.
- بعد إضافة المكوّن، يتحدث جدول الوصفة داخل نفس النافذة بدون إغلاق وفتح النافذة من جديد.
- حفظ الوحدة والكمية المدخلتين كما هما والتحقق من الحفظ من قاعدة البيانات قبل عرض نجاح للمستخدم.
- عند إعادة فتح الوصفة تظهر الوحدة والكمية المحفوظتان فعليًا.
- إذا تعذر تأكيد الحفظ لا تظهر رسالة نجاح وهمية.
- تحسين شكل التركيز في حقل البحث وإزالة الإطار الأسود الافتراضي للمتصفح.
