# Maria CFO Web v0.10

نسخة اختبار تركز على فواتير الشراء والموردين.

## قبل الاختبار
1. شغّل مرة واحدة في Supabase SQL Editor:
   `database/Maria_CFO_Web_v0.10_Migration.sql`
2. استبدل ملفات المشروع فوق Maria-CFO-Web-Live.
3. لا تستبدل `config.js`؛ هذه الحزمة لا تحتويه أصلًا.
4. نفّذ Ctrl + F5 في المتصفح.

## تحليل صورة الفاتورة
تمت إضافة Edge Function جديدة:
`supabase/functions/document-ocr/index.ts`

لتفعيل زر «تحليل صورة الفاتورة» يجب إنشاء/تحديث Edge Function في Supabase باسم:
`document-ocr`
ولصق محتوى `index.ts` ثم Deploy.

تستخدم نفس Secret الموجود مسبقًا:
`GEMINI_API_KEY`
ولا يحتاج المفتاح إلى الوجود داخل الموقع.

## أهم تغييرات v0.10
- ظهور اسم المورد في قائمة الفواتير.
- حذف المسودة.
- إلغاء الفاتورة المنشورة بحركة مخزون عكسية مع حفظ السجل التاريخي.
- تعديل وحذف بنود المسودة.
- «مواد هذا المورد» أصبحت قائمة تراكمية من تاريخ شراء هذا المورد، لا آخر فاتورة فقط.
- اقتراحات المورد لا تعمل للشراء المباشر بلا مورد.
- مواد المورد لا تضاف مباشرة؛ تظهر غير محددة مع Checkbox ويختار المستخدم ما يحتاجه ويعدل الكمية والوحدة والسعر والخصم.
- تحليل صورة فاتورة ومراجعة البنود قبل إضافتها.
