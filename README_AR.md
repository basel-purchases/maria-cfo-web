# Maria CFO Web v0.5

نسخة تحسين الوصفات والتحويلات.

## طريقة التحديث

انسخ محتويات هذا المجلد مباشرة فوق ملفات `Maria-CFO-Web-Live` واعمل Replace.

الحزمة لا تحتوي:
- `config.js`
- `.git`
- `.gitignore`

لذلك إعدادات Supabase والـRepository المحلي لا تتغير.

## قبل الاختبار

شغّل مرة واحدة في Supabase SQL Editor:

`database/Maria_CFO_Web_v0.5_Migration.sql`

الـMigration تراكمي ويشمل تعديلات v0.4 أيضًا، ويمكن تشغيله أكثر من مرة بأمان.

## أهم تغييرات v0.5

- إصلاح إضافة مكوّن الوصفة عبر RPC ثابت بدل تخمين أعمدة قاعدة البيانات من المتصفح.
- حفظ الوحدة والكمية التي أدخلها المستخدم، مع تحويل الكمية تلقائيًا إلى وحدة المخزون الأساسية للحسابات.
- تحسين زر تحويل الوحدة بصريًا.
- وضع الوحدة المرجعية على اليمين والوحدة الجديدة على اليسار.
- إضافة خيار **معكوس** لوحدات الاستخدام، مثل: `1 ملعقة = 50 غرام` بدل إجبار المستخدم على حساب `1 غرام = كم ملعقة`.
- استمرار دعم العلاقة العادية مثل: `1 كيلوغرام = 25 ملعقة`.
- عرض مكونات الوصفة بالوحدة التي اختارها المستخدم بدل عرض وحدة المخزون فقط.
