# Maria CFO Web v0.6

نسخة تطويرية لموقع Maria CFO متصلة بـ Supabase.

## قبل التشغيل
لا تستبدل ملف `config.js` الموجود لديك في مشروع GitHub المحلي. هذه الحزمة لا تحتويه أصلًا.

نفّذ مرة واحدة في Supabase SQL Editor:

`database/Maria_CFO_Web_v0.6_Migration.sql`

ثم انسخ محتويات ZIP مباشرة فوق مجلد `Maria-CFO-Web-Live` واعمل Replace.

## أهم ما في v0.6
- بحث وترقيم صفحات للمواد.
- إدارة وحدات أبسط بعلاقة تحويل واحدة.
- إجراء عكسي للتحويل.
- إضافة وحدات جديدة بالكتابة المباشرة.
- تبويب إدارة الوحدات في الإعدادات.
- وحدة «سحارة».
- إصلاح تحديث مكوّن الوصفة الموجود بدل فشل التكرار.
- زر حفظ واضح للوصفة.

## ملاحظة
كل مكوّن وصفة يُحفظ عند الضغط على «إضافة مكوّن». زر «حفظ الوصفة وإغلاق» موجود ليجعل نهاية العمل واضحة للمستخدم.
