# Maria CFO Web — الإصدار 1.0

## ما الذي تغيّر؟

- أصبح اسم القسم في الشريط الجانبي والصفحة **الأوردرات**، وعنوان رفع الملف **إدخال الأوردرات**، ومؤشر الإيرادات **إجمالي المبيعات**.
- أُزيل اسم النظام الخارجي من التسميات المرئية. بقيت أسماء بعض ملفات الكود والدوال وقاعدة البيانات القديمة دون تعديل لحماية التوافق مع الاستيرادات والبيانات الحالية.
- زادت المسافة بين أرقام الإحصاءات وتسمياتها لتسهيل القراءة.
- تُعرض أسعار الأصناف **غير المطابقة أولاً** بتمييز أحمر، ثم الأصناف الجديدة، ثم الأسعار **المطابقة** بتمييز أخضر. يستمر زر قرار السعر بالعمل على الصنف الصحيح حتى بعد الفرز.
- تظهر العملة السورية بصيغة **12,500 ل.س** في واجهات البرنامج، بدل SYP، مع فواصل الآلاف. يظل رمز `SYP` محفوظًا كما هو في معاملات قاعدة البيانات والتكاملات والتصديرات الهيكلية حتى لا يتضرر توافق البيانات.
- تحسين عرض جداول معاينة الأسعار على شاشة الهاتف لعدم تمديد الصفحة أفقياً.
- تحديث علامات التخزين المؤقت لملفات JS وCSS إلى الإصدار 1.0.

## طريقة التثبيت

1. أنشئ نسخة احتياطية من ملفات الموقع ومن قاعدة البيانات.
2. تأكد أن تحديثات قاعدة البيانات للإصدارات السابقة، وخصوصًا v0.41، مطبقة بالفعل.
3. فك ضغط **web-v1.0.zip** ثم ارفع **كل الملفات** إلى الاستضافة مع الاستبدال الكامل.
4. لا تحذف ملف **config.js** الموجود على الاستضافة ولا تستبدله؛ فهو **غير موجود داخل الحزمة**.
5. حدث الصفحة بقوة (Ctrl+Shift+R) أو افتحها في نافذة خاصة، وتأكد أن الإصدار المعروض هو **Web v1.0**.
6. افتح «الأوردرات» وجرّب معاينة ملف؛ راقب تمييز غير المطابق ومطابقة اسم الصنف مع قرار السعر.

## قاعدة البيانات

**لا يوجد ملف SQL جديد لـ v1.0**؛ التحديث يقتصر على واجهة الاستخدام وتسميات العملة مع الحفاظ على نفس APIs وقاعدة البيانات. لا تعاود تطبيق ملفات SQL التاريخية بلا حاجة.

## فحوصات الجودة

- اجتازت اختبارات Node المحلية 272 اختبارًا، و7 اختبارات متروكة، دون فشل.
- تم تدقيق صياغة ملفات JavaScript وفحص معاينة للأوردرات ومقارنة الأسعار على سطح المكتب والهاتف ببيانات اختبارية.
- **لم يتم اختبار هذا الإصدار مع قاعدة بيانات Supabase الإنتاجية**؛ يُنصح بفحص رفع ملف تجريبي قبل الاعتماد اليومي.
