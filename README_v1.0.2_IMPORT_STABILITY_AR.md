# Maria CFO Web v1.0.2 — إصلاح تعليق الإدخالات السريعة وتوحيد التخطيط

**هذا تحديث واجهة ومعالجة أخطاء فوق v1.0.1. لا يحتاج إلى تشغيل SQL جديد، ولا تصفير البيانات، ولا تعديل ملف Excel المصحح.**

## سبب العطل

كانت الدالة الخاصة بتأكيد الاستيراد تقرأ `parsed.records.length` لجميع أنواع ملفات Excel. لكن النوع الأول (المواد والمنيو والوصفات) يستخدم بنيتين منفصلتين `parsed.materials` و`parsed.dishes` ولا يحتوي على `parsed.records`؛ لذلك يطلق المتصفح `TypeError` قبل فتح نافذة التأكيد أو استدعاء Supabase، ويبقى الزر معطلًا دون تفسير.

## ما تم إصلاحه

1. عدد السجلات عند تأكيد النوع الأول = عدد المواد + عدد أصناف المنيو، أي **399 + 197 = 596 سجلًا** في ملف الاختبار المرفق. لا تُضاف الوصفات كسجلات منيو منفصلة؛ فهي بيانات ضمن الأصناف.
2. إحاطة التأكيد باستعادة الزر عند الإلغاء أو فشل فتح النافذة.
3. إظهار شاشة انتظار بحالة واضحة وعدّاد للثواني، بدل زر رمادي دون تفسير.
4. إظهار نتيجة نجاح أو فشل **داخل الصفحة** مع رمز خطأ الخادم إن وُجد، وإتاحة إعادة محاولة الملف نفسه. أضيف حدّ انتظار للاتصال مدته دقيقتان؛ عند انتهائه تكون حالة الخادم غير محسومة حتى مراجعة سجل الاستيراد.
5. إظهار أقسام الصفحة بعرض موحّد، مع ترتيب إحصاءات الملف الأربعة على صف واحد في الكمبيوتر، ثم صفين في الشاشات الضيقة.
6. المحافظة على الاستيراد الأصلي الذري (ملف واحد في معاملة قاعدة بيانات واحدة)، وفحص بصمة الملف لمنع تكراره، وتراجع 24 ساعة وفق منطق قاعدة البيانات الموجود سابقًا.

## التثبيت

1. فك ضغط `web-v1.0.2-QUICK-IMPORT-FIX.zip`، وارفع جميع الملفات واستبدل القديمة.
2. **احتفظ بملف `config.js` الموجود على الاستضافة**؛ لا يوجد في الحزمة.
3. لا تشغّل SQL إضافيًا؛ استمر باستخدام قاعدة البيانات المصححة للإصدار v1.0.1.
4. حدّث الصفحة تحديثًا قويًا (Ctrl+Shift+R) ثم افتح «الإدخالات السريعة».
5. اختر `01 · المواد والمنيو والوصفات` وارفع `01_المواد_والمنيو_والوصفات_مصحح.xlsx` الموجود لديك سابقًا.
6. تأكد من المعاينة: 399 مادة، 197 صنفًا، 157 وصفة مكتملة البيانات، 40 بحاجة استكمال.
7. اضغط «تأكيد الاستيراد». **ينبغي أن تظهر نافذة تعرض 596 سجلًا**؛ بعد الموافقة يُعرض الانتظار ثم النتيجة الحقيقية القادمة من Supabase.
8. أرسل لقطة من **نتيجة الحفظ أو رسالة خطأ الخادم**؛ لا تعتمد مجرد المعاينة كدليل على الحفظ.

إذا انتهت مهلة الاتصال أو انقطع الإنترنت، لا تصفّر قاعدة البيانات مجددًا. راجع سجل الإدخالات أولًا؛ أعد رفع **الملف نفسه** فقط عند الحاجة لأن التكرار محمي ببصمة الملف.

## فحوص محلية

- نجح **279 اختبارًا آليًا** وفشل **0**، مع **7 اختبارات متروكة**.
- جُرِّبت واجهة الاستيراد مع ملف XLSX المصحح فعليًا في متصفح مع محاكاة استجابة Supabase: حالة نجاح على الحاسوب والهاتف، وحالة فشل على الحاسوب؛ نافذة التأكيد تعرض 596 سجلًا ولا توجد أخطاء JavaScript غير متوقعة.
- لم يُنفَّذ استيراد على قاعدة Supabase الإنتاجية. نجاح الاستيراد الفعلي يعتمد على استجابة الخادم وبياناته الحالية.
