# Maria CFO v0.17 — نشر مساعد الذكاء الاصطناعي في Supabase

هذا الإصدار ليس تعديل واجهة فقط. الملف `supabase/functions/assistant/index.ts` هو **كود خادم** مستقل يجب نشره في Edge Functions باسم `assistant`. مجرد رفع ZIP على GitHub Pages لا يشغّل المساعد الجديد.

## طريقة 1 — Supabase Dashboard (الأسهل)

1. افتح مشروعك في Supabase → **Edge Functions** → `assistant`.
2. اختر Edit Code أو إنشاء نسخة جديدة من الدالة بالاسم نفسه.
3. **لأن المحرر قد يقبل ملفًا واحدًا فقط**، افتح `supabase/functions/assistant/dashboard-single-file.ts` وانسخ محتواه كاملًا؛ لا تستخدم `index.ts` منفردًا لأنه يستورد `agent-core.js` و`project-knowledge.js`.
4. اضغط Deploy. افحص أن الحالة `Active` وأن Logs لا تحتوي خطأ بدء تشغيل.
5. في Supabase → Edge Functions → Secrets تحقق من وجود `GEMINI_API_KEY`؛ يمكنك إضافة `GEMINI_MODEL` بقيمة `gemini-3.5-flash-lite`. لا تطبع المفتاح ولا تنقله إلى GitHub.
6. أبقِ حماية JWT/Auth مفعلة، حيث تتطلب الدالة تسجيل دخول المالك وقائمة `app_users` وRLS.

## طريقة 2 — Supabase CLI عند توفره

من نسخة مشروع تحتوي مجلد `supabase/functions/assistant`:

```bash
supabase login
supabase link --project-ref YOUR_PROJECT_REF
supabase functions deploy assistant
```

لا تكتب الأسرار في هذا الدليل. أضفها من لوحة Supabase Secrets.

## اختبار الاتصال بوضوح

بعد نشر SQL v0.17 وEdge Function ثم الموقع:
- افتح المساعد. زر «اختبر Gemini الآن» يظهر بعد تهيئة الخادم، لكنه **ليس إثباتًا أن Gemini رد فعلًا** حتى تضغط عليه وتظهر نتيجة الاختبار الحقيقي.
- اسأله «ما مبيعات اليوم؟» ثم «أضف موظف اختبار يومي براتب 100» باسم غير مستخدم.
- إذا ظهرت رسالة خطأ: افتح **Edge Functions → assistant → Logs** وانسخ رسالة الخطأ مع حالة HTTP **دون أي أسرار**؛ قد يكون السبب نموذج غير متاح للمفتاح أو حصة 429 أو مفتاح/صلاحيات 401/403 أو مهلة 502.
- إن تعطّل Gemini، ستظل أوامر إنشاء الموظفين الصريحة وبعض القراءات المالية المباشرة متاحة؛ قراءة الصور أو فهم الطلبات المركبة يعتمد على مزود النموذج.

## ملاحظات الأمان والتكلفة

- لا ترسل `service_role` أو مفتاح Gemini إلى المتصفح. العمليات تنفذ تحت JWT المالك بصلاحيات RLS.
- لا يكتب الذكاء الاصطناعي إلى `cashbox_transactions` أو `inventory_movements` مباشرة.
- المدفوعات/الترحيل والمصروفات تستهلك موافقة منفصلة بمدة صلاحية 15 دقيقة.
- المسودات والتحديثات البسيطة تنفذ مباشرة إذا استوفيت الحقول المطلوبة.
- نشر المشروع وتشغيله قد يخضعان لحدود Free Tier؛ راجع سياسة خصوصية بيانات Gemini قبل إرسال مستندات حقيقية تحتوي بيانات حساسة.
- إذا لم تجد ملف المساعد السابق أو لم تنشر SQL، لا تعالج ذلك بإضافة أعمدة أو تعطيل RLS.
