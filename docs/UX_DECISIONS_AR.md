# قرارات UX — Maria CFO Web v0.4

## المواد

- المستخدم يستطيع تعديل اسم المادة إذا أخطأ في الكتابة.
- الكود ليس عبئًا على المستخدم؛ إذا تركه فارغًا ينشئ Maria CFO كودًا تلقائيًا.
- يظهر الكود في الجدول بدل الشرطات الفارغة.
- وحدة المخزون الأساسية منفصلة عن وحدة الشراء.
- التحويل مطلوب فقط عندما تختلف وحدة الشراء عن وحدة المخزون.

## التحويلات

- التحويل الخاص بالمادة هو المرجع الأساسي للوحدات غير القياسية.
- وحدة شراء: `1 وحدة جديدة = X من الوحدة المرجعية`.
- وحدة استخدام/وصفة: `1 وحدة مرجعية = X من الوحدة الجديدة`.
- يمكن بناء سلسلة تحويلات دون مطالبة المستخدم بالعودة لشاشة أخرى.

## الوصفات

- قائمة الوحدة لا تعرض كل وحدات النظام عشوائيًا؛ تعرض فقط الوحدات المعرفة للمادة.
- زر `+ تحويل` موجود بجانب الوحدة لإضافة وحدة استخدام أثناء إعداد الوصفة.
- المادة والوحدة والكمية تظهر في سطر واحد على شاشة الكمبيوتر.
- مكونات الوصفة قابلة للتعديل والحذف.

## الوجبات

- بعد إنشاء الوجبة يمكن تعديل الاسم وسعر البيع وFood Cost والخصم الافتراضي.
- الخصم الافتراضي هو اقتراح للأوردر الجديد ويمكن تغييره عند البيع.
