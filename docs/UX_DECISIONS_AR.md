# قرارات UX — Maria CFO Web v0.9

- لا نجبر المستخدم على مغادرة فاتورة الشراء لإضافة مادة ناقصة.
- التحويل هو علاقة واحدة خاصة بالمادة؛ لا نعرض للمستخدم مفهومين منفصلين باسم "وحدة شراء" و"وحدة استخدام".
- في سياق الفاتورة نعرض ببساطة: **المادة + الوحدة + الكمية + السعر**.
- إذا كانت المادة غير موجودة، يتم إنشاؤها في نفس النافذة بأقل حقول ممكنة.
- أسماء المواد لا تتكرر بصمت؛ الاسم المكرر يعاد استخدام سجله الحالي بدل إنشاء نسخة ثانية.
- التحويلات التي يعرفها النظام تستخدم في الشراء والوصفات معًا.
