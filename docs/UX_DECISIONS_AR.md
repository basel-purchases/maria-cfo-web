# قرارات UX — Maria CFO Web v0.5

## التحويلات

الهدف أن يصف المستخدم العلاقة بالطريقة الطبيعية بالنسبة له، لا أن يقوم بحساب مقلوب يدويًا.

الوضع العادي:
- `1 كيلوغرام = 25 ملعقة`

الوضع **معكوس**:
- `1 ملعقة = 50 غرام`

في الحالتين يخزن النظام معاملًا موحدًا بالنسبة لوحدة المخزون الأساسية، لذلك تبقى تكلفة الوصفات والمخزون متسقة.

## الوصفة

- المادة والوحدة والكمية تظهر في صف واحد على الكمبيوتر.
- الوحدة ليست اختيارية.
- لا تظهر في قائمة الوحدة إلا الوحدات المرتبطة بالمادة.
- يمكن إضافة تحويل من نفس نافذة الوصفة.
- بعد حفظ التحويل تعود الوحدة الجديدة إلى الوصفة تلقائيًا.
- الحفظ يتم عبر RPC في قاعدة البيانات، وليس عبر تخمين أسماء الأعمدة من الواجهة.

## قاعدة الراحة

إذا كانت العلاقة الأسهل للمستخدم معروفة بصيغة `الوحدة الصغيرة = كمية من الوحدة المرجعية` فيجب السماح بكتابتها مباشرة بدل إجباره على حساب المعكوس.
