# قرارات UX — Maria CFO Web v0.6

1. المستخدم لا يحتاج معرفة الفرق التقني بين وحدة شراء ووحدة استخدام عند تعريف المادة.
2. المادة لها وحدة مخزون أساسية، ويمكن ربط أي وحدات أخرى بها بعلاقة تحويل واحدة.
3. نفس الوحدات المرتبطة بالمادة متاحة في الفواتير والوصفات.
4. نافذة التحويل تحتوي خيار «إجراء عكسي» بدل زرين منفصلين.
5. الوحدات قابلة للبحث والإنشاء مباشرة عند الحاجة.
6. إدارة كتالوج الوحدات موجودة في الإعدادات ضمن تبويب مستقل.
7. المواد تُعرض بترتيب الإدخال، مع بحث بالاسم/الكود وPagination لتقليل التشويش.
8. إذا أضاف المستخدم مادة موجودة أصلًا داخل نفس الوصفة، فالمقصود تعديلها وليس إنشاء تكرار جديد.
9. زر «حفظ الوصفة وإغلاق» مطلوب بصريًا حتى لو كانت المكونات تحفظ فورًا.
