# Maria CFO Web — قرارات UX v0.1

## لماذا انتقلنا للموقع أولًا؟
الموقع أسرع في التعديل والاختبار، ولذلك نعتمد عليه لتثبيت تدفقات الاستخدام قبل إعادة بناء تطبيق الهاتف.

## القائمة الرئيسية
القائمة تعرض أقسامًا عامة فقط:
1. الرئيسية
2. الإدخالات الأساسية
3. التشغيل اليومي
4. الموظفون والرواتب
5. الحفلات
6. الإحصائيات والتقارير
7. المساعد الذكي
8. الإعدادات

داخل كل قسم توجد بطاقات تشرح ما الذي يفعله القسم ومتى يستخدم.

## الرئيسية
تعرض فقط معلومات تحتاج المتابعة السريعة:
- مبيعات اليوم
- النتيجة اليوم
- مصروفات اليوم
- عدد الأوردرات
- أهم التنبيهات
- الحفلة القادمة
- تقدم الإعداد الأولي

لا يظهر Food Cost العام في الرئيسية. Food Cost يعرض داخل الوجبات والتقارير لأنه قد يختلف من منتج لآخر.

## المورد
المورد اختياري أمام المستخدم. عند عدم إدخاله يستخدم النظام سجلًا تقنيًا داخليًا للشراء المباشر حتى تبقى قاعدة البيانات متوافقة، ولا يظهر هذا السجل كإلزام للمستخدم.

## AI
لا تعرض أكواد مثل 502 للمستخدم. الدالة تعيد المحاولة حتى 3 مرات. بعد الفشل النهائي تعيد HTTP 200 مع رسالة عربية مفهومة وسبب مبسط، بينما يبقى الخطأ التقني في Logs فقط.
