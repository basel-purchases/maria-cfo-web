# اختبار الموردين وفواتير الشراء — v0.10

1. أنشئ فاتورة باسم مورد حقيقي مثل «باسل» وانشر فيها سكر وشاي.
2. أنشئ فاتورة ثانية للمورد نفسه وانشر شاي وبطاطا.
3. أنشئ فاتورة ثالثة للمورد نفسه وانشر سكر وبطاطا.
4. في فاتورة رابعة للمورد نفسه اضغط «مواد هذا المورد».
   المتوقع: سكر + شاي + بطاطا مرة واحدة لكل مادة.
5. لا تحدد أي مادة: يجب ألا يضاف شيء.
6. حدد بطاطا فقط، غيّر الكمية والسعر ثم أضفها.
7. أضف خيار كبند جديد وانشر الفاتورة.
8. في الفاتورة الخامسة يجب أن تصبح القائمة: سكر + شاي + بطاطا + خيار.
9. أنشئ فاتورة بدون مورد: زر «مواد هذا المورد» يجب أن يكون غير فعال.
10. أنشئ Draft واحذفه: يجب أن يختفي بدون تأثير على المخزون.
11. انشر فاتورة بلا دفعات ثم ألغها: يجب أن يسجل النظام حركة عكسية للمخزون وتظهر الحالة «ملغي».
12. جرّب «تحليل صورة الفاتورة» بعد نشر Edge Function `document-ocr`، وراجع البنود قبل إضافتها.
