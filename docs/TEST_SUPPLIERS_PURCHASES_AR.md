# اختبار الموردين وفواتير الشراء — v0.9

## 1. فاتورة بدون مورد
- أنشئ فاتورة واترك المورد فارغًا.
- أضف مادة وانشر الفاتورة.
- تأكد أن المخزون زاد.

## 2. تحويل وحدة
- مادة السكر بوحدة مخزون: كيلوغرام.
- أضف تحويلًا: `1 شوال = 30 كيلوغرام`.
- في الفاتورة اختر شوال، كمية 2.
- أضف البند ثم انشر الفاتورة.
- يجب أن يزداد المخزون 60 كيلوغرام.

## 3. مادة جديدة من الفاتورة
- اضغط `+ مادة جديدة` داخل نافذة البند.
- اكتب اسمًا جديدًا ووحدة المخزون.
- احفظ؛ يجب أن يتم اختيار المادة الجديدة تلقائيًا وتكمل الفاتورة دون مغادرة الصفحة.

## 4. منع التكرار
- داخل `+ مادة جديدة` اكتب اسم مادة موجودة بالفعل، مع اختلاف مسافات أو حالة أحرف إن وجدت.
- يجب أن يظهر تنبيه بأن المادة موجودة، ويختار السجل الموجود بدل إنشاء سجل آخر.

## 5. مورد جديد
- أنشئ فاتورة باسم مورد جديد.
- بعد الحفظ راجع قسم الموردين وتأكد أنه ظهر مرة واحدة.
