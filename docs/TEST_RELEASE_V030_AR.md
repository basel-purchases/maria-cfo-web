# فحص استيراد Maria CFO Web v0.30

**قبل الاختبار**: شغّل SQL الترقية ثم انشر الموقع كاملًا مع بقاء `config.js` الموجود على الخادم.

- [ ] «الإدخالات السريعة» موجودة قبل «الإعدادات» في القائمة الجانبية.
- [ ] لا يظهر زر استيراد منفصل للوصفات في قسم «الإدخالات الأساسية» أو شاشة المنيو.
- [ ] عند اختيار ملف غير مناسب تظهر رسالة واضحة، ولا يُدخل شيء.
- [ ] الملف 01: معاينة المواد/المنيو، نجاح المنيو المسعّر بلا وصفات كاملة وظهور «غير محسوبة» للتكلفة.
- [ ] الملف 01: الوصفات «منتهي» فقط تظهر تكلفتها عند وجود أسعار المواد ومقاديرها.
- [ ] الملف 02: الأساسيات فقط؛ لا زيادة لأسماء مواد المطبخ أو أصناف المنيو بسبب رفعه.
- [ ] الملف 03: الموردون وحساباتهم التاريخية فقط؛ لا تحصيل أو قبض تلقائي.
- [ ] الملف 04: مسودات أوردرات قابلة للمراجعة دون حركات مالية، مع عرض مراجعة الفروقات.
- [ ] بعد الرفع يظهر اسم الملف ووقته والنتيجة في سجل الإدخالات.
- [ ] الضغط على التراجع خلال 24 ساعة قبل تعديل البيانات يعيد الحالة السابقة ويحفظ سجل العملية.
- [ ] التراجع عن عملية أقدم من الأحدث ممنوع حتى يُتراجع عن الأحدث أولًا.
- [ ] التراجع عن أوردر منشور أو بيانات تغيّرت بعد الرفع مرفوض للحماية.
- [ ] بعد انتهاء 24 ساعة تختفي إمكانية التراجع.
- [ ] لا توجد أخطاء JavaScript في وحدة التحكم أثناء المعاينة.

> قد تظهر استثناءات عند التفاعل مع بيانات فعلية غير متوقعة لم تشملها الاختبارات المحلية. سجّل نص الخطأ واسم الملف قبل محاولة إعادة الرفع.
