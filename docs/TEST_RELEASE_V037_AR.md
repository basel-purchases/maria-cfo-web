# اختبار قبول v0.37 — الحفلات

- [ ] إنشاء مجموعة «المقبلات» ثم «الحلويات» بعد «الصحن الرئيسي» دون تعطل.
- [ ] إعادة فتح الحفلة والتأكد أن كل المجموعات محفوظة؛ المجموعة الأصلية لم تُفقد.
- [ ] نقل مكوّن إلى مجموعة أخرى من نافذة التعديل ثم فحص أن التكلفة الإجمالية لم تتضاعف.
- [ ] إضافة صنف مستقل، ثم إضافته لاحقًا إلى مجموعة عبر تعديل المجموعة.
- [ ] فتح نافذة المكوّن وكتابة «2» في عدد الحصص، ثم فتح نافذة الوحدة السريعة وإغلاقها؛ يجب أن يبقى «2» كما هو.
- [ ] إضافة «سيخ كباب» = 10 أسياخ في «كيلو كباب»؛ عودته للاختيار تلقائيًا وحساب 0.2 كيلو عند تقديم سيخين.
- [ ] تعريف حصة بلا ربط مادة مخزون، ثم إعادة فتحها لاحقًا والتحقق من حفظ التحويل.
- [ ] ربط وحدة بمادة موجودة في الوصفة بقيمة مباشرة، ثم اختبار اتجاه التحويل العكسي (مثل 1 كغ = 10 أسياخ).
- [ ] محاولة إضافة وحدة باسم مكرر لنفس الصنف؛ ينبغي منع التكرار.
- [ ] محاولة إنشاء مجموعة باسم موجود؛ ينبغي منع تكرار الاسم ضمن الحفلة.
- [ ] إضافة جاط تبولة لكل 4 أشخاص على طاولتين؛ يجب حساب العدد لكل طاولة لا للجميع معًا.
- [ ] حذف مجموعة بعد التأكيد؛ حذف مكوناتها فقط، وترك المجموعات الأخرى سليمة.
- [ ] فحص تصدير Excel وPDF لمكونات كل مجموعة مستقلة.
- [ ] تجربة شاشة ضيقة للهاتف وفحص ظهور زر إضافة الوحدة دون خروج حقول النموذج عن النافذة.
- [ ] التأكد من أن التحويل الجديد لم ينتج حركة صندوق، أو تعديلًا بأرصدة المخزون عند تعريفه فقط.
