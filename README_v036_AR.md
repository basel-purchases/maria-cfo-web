# Maria CFO Web — v0.36

## التحديثات
- تحديد الحصص الفعلية من صنف المنيو في مكونات الحفلة: مثل سيخين كباب لكل ضيف بدل احتساب كيلو كامل.
- ربط الحصة بمكافئ وجبة المنيو، واستخدام تكلفة الوصفة نفسها؛ مثال: إذا كان الكيلو يساوي 10 أسياخ حسب تعريفك، فإن سيخين يساويان 0.2 من وجبة الكيلو.
- حفظ تحويلات الحصص المحددة للصنف وإعادة استخدامها في حفلات لاحقة.
- إنشاء صحن رئيسي مركب، وإضافة عدة مكونات له، ويُقدّم الصحن للضيف مع احتساب تكلفة كل مكون بصورة مستقلة.
- توضيح مسميات الكميات في شاشة الضيافة وتحسين شكل الأزرار والنوافذ للكمبيوتر والهاتف.

## خطوات التثبيت
1. احتفظ بنسخة احتياطية من الموقع وقاعدة البيانات.
2. تأكد من تطبيق SQL المصحح v0.34 وتحديث v0.35 قبل التحديث الجديد.
3. شغّل الملف `database/Maria-CFO-Web-v0.36-Event-Servings-Main-Plate.sql` على Supabase > SQL Editor.
4. فك ضغط `web-v0.36.zip` وارفع **كل محتوياته** إلى جذر الموقع واستبدل الملفات القديمة. احتفظ بملف `config.js` الموجود لديك؛ فهو غير مضمن في الحزمة.
5. حدّث الصفحة تحديثًا قويًا، ثم اختبر إعداد حفل تجريبي في تبويب «مكونات الضيافة».

## تنبيهات
- لا يفترض البرنامج كم سيخًا في الكيلو؛ أنت تحدد تحويل الصنف مرة واحدة بحسب مطبخك، ثم يعاد استخدامه.
- ترتبط تكلفة الحصص بدقة وصفة صنف المنيو وأسعار مواده. إن كانت تكلفة الوصفة ناقصة، فستظهر الحاجة لاستكمالها.
- نتيجة اختبارات JavaScript المحلية: 223 ناجحًا، صفر فشل، و7 متروكة. لم تُختبر هذه النسخة على قاعدة Supabase الحية لديك.
