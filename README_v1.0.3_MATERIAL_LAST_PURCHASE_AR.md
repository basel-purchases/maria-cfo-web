# Maria CFO Web v1.0.3 — تاريخ آخر شراء معروف للمواد

## التحديث

- شاشة «المواد والكميات والأسعار»: عمود «تاريخ آخر شراء معروف» بجوار آخر سعر شراء معروف.
- يعتمد على الحقل `public.materials.last_purchase_at` الموجود فعلًا في Supabase؛ لا يستحدث بيانات أو يغيّر سجل المشتريات.
- التواريخ بصيغة يوم/شهر/سنة، وتبقى «—» للمواد التي لا نعرف تاريخ شراء لها.
- سجل `last_purchase_at` قد يتضمن تاريخ السعر المرجعي المستورد من Excel، وليس فقط فواتير الشراء المنشورة داخل النظام؛ لذا استخدمنا وصف «معروف» في عنوان العمود.
- التاريخ موجود أيضًا عند تصدير كامل نتائج الفلترة إلى Excel أو PDF.

## التثبيت

1. احتفظ بملف `config.js` الموجود لديك في المشروع/الاستضافة ولا تحذفه ولا تستبدله؛ غير موجود في الحزمة.
2. استبدل ملفات الموقع الأخرى بمحتوى هذه الحزمة وارفعها إلى فرع النشر كالمعتاد.
3. لا تشغّل SQL، ولا تعِد استيراد المواد ولا تُصفّر القاعدة.
4. حدّث الصفحة بقوة (Ctrl+Shift+R) وافتح «المواد والكميات والأسعار»؛ يجب ظهور العمود والتواريخ المتاحة.
5. اختبر التصدير Excel/PDF للتأكد أن العمود موجود حتى عند تصفية المواد والانتقال بين الصفحات.

## حدود التحقق

اختُبر الكود محليًا. لم أُجرِ أي تعديل مباشر على Supabase، ولم أختبر واجهة الإنتاج بحسابك الحقيقي.
