# نتائج فحص v1.0.25

النتائج المحلية الفعلية: **441 اختبار Node ناجحًا من 448؛ 7 متجاوزة لأن ملفات الاختبار الأصلية الخاصة ليست موزعة مع المشروع؛ صفر إخفاقات.** السجل الكامل في node-tests.tap.txt.

نجحت **15 تجربة Chromium** للواجهة مع API محاكاة وبيانات مصطنعة. browser-results.json يسرد الحالات، والصور المرفقة من هذه البيانات وليست حفلات المستخدم. شاشة الهاتف بعرض 390px، والنموذج قابل للتمرير الداخلي.

SQL الجديد لم ينفذ على محرك PostgreSQL في بيئة الإعداد أو على Supabase الخاصة بالمستخدم. اختبارات نص SQL وعقوده لا تثبت تنفيذ معاملاته. الاختبار على بيئة تجريبية مطابقة شرط قبل النشر. راجع tests/V125_STAGING_ACCEPTANCE_AR.md ودليل الإصدار.

جميع ملفات المشروع الأصلي البالغ عددها 333 موجودة في الحزمة، مع تعديلات الواجهة والنسخة والاختبارات اللازمة وإضافات الإصدار. تحديث اختبارات الإصدارات السابقة اقتصر على مراجع رقم النسخة الحالية، وعلى اسم محمل المشتريات الخارجية الجديد في اختبار v038؛ لم تُلغ اختبارات الميزات.
