# Maria CFO — v0.40.1 | تصحيح الشاشة البيضاء

## لماذا اختفت الواجهة؟

احتوى الإصدار v0.40 على خطأ في صياغة رسالة عربية داخل الملف `js/pages/events-v034.js`، فتوقف تحميل وحدة التطبيق كاملة قبل عرض تسجيل الدخول. لا يشير هذا الخطأ إلى حذف بيانات قاعدة البيانات.

## ما الذي تم إصلاحه؟

- تصحيح النص العربي غير المقتبس.
- تغيير إصدار روابط ملفات JavaScript لمنع تشغيل ملفات v0.40 المحفوظة مؤقتًا في المتصفح.
- إظهار شاشة فشل تحميل مفهومة بدل شاشة صامتة عند تعذر بدء التطبيق.
- إضافة اختبار جديد لتحليل وحدات JavaScript وربطها، لمنع تكرار هذه الحالة.

## التثبيت السريع

1. لا تشغّل أي SQL إضافي لهذا التصحيح؛ أبق قاعدة بياناتك كما هي.
2. فك ضغط `web-v0.40.1-HOTFIX.zip`، وارفع **كامل محتوياته** إلى مجلد الموقع واستبدل الملفات السابقة.
3. لا تستبدل ملف **`config.js`** الحالي؛ النسخة لا تحتويه.
4. افتح الموقع باستخدام نافذة خاصة أو نفذ إعادة تحميل قوية (`Ctrl+Shift+R` أو `Ctrl+F5`).
5. تحقق من ظهور شاشة تسجيل الدخول أو لوحة التحكم وظهور `Web v0.40.1` في الشريط الجانبي بعد تسجيل الدخول.

لا تغيّر هذه النسخة وظيفة الحجز أو الدفع أو حساب التكاليف. لم يتم الاتصال بقاعدة البيانات الحية، واختبار المتصفح داخل هذه البيئة لم يكتمل بسبب منع طلبات الشبكة المحلية؛ فُحص نحو التطبيق وربط الوحدات والاختبارات المحلية بدلًا منه.

## في حال استمرار الشاشة البيضاء

- تأكد من رفع جميع الملفات إلى **المجلد نفسه** الذي يحتوي `index.html` الأصلي، وليس داخل مجلد فرعي `web-v0.40.1`.
- جرّب فتح نافذة خاصة لمنع تأثير ذاكرة المتصفح.
- افتح أدوات المطور `F12` ثم `Console` وأرسل أول رسالة خطأ باللون الأحمر. ولا ترسل ملف `config.js` أو أي مفاتيح خاصة.
