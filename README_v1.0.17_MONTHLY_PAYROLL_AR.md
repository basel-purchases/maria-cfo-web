# Maria CFO Web v1.0.17 — الرواتب الشهرية والحضور الافتراضي

## التثبيت
1. قبل أي تحديث خذ نسخة احتياطية من Supabase، ولا تشغّل الترحيل في بيئة الإنتاج لأول مرة أثناء صرف حقيقي.
2. افتح Supabase SQL Editor، وشغّل ملف `database/Maria-CFO-Web-v1.0.17-Monthly-Payroll-Default-Attendance.sql` كاملًا.
3. تحقّق من ظهور أسماء أربع دوال في نتيجة الاستعلام الأخيرة.
4. ارفع **كل ملفات** المشروع من ZIP إلى الاستضافة. لا تستبدل أو ترسل `config.js`.
5. حدّث المتصفح تحديثًا قويًا، وتأكد من ظهور Web v1.0.17.

## قواعد الرواتب المعتمدة
- الموظف **الشهري**: الراتب عن فترة الخدمة كاملة (مع مراعاة تاريخ التعيين وإنهاء الخدمة) دون تسجيل حضور يومي. اليوم غير المسجّل **ليس غيابًا**.
- الدوام أو الغياب أو النقص المُسجّل كاستثناء يبقى مؤثرًا عند احتساب الخصومات حسب إعدادات الموظف. كذلك المكافآت والخصومات اليدوية وسلف الموظفين.
- إجمالي «مجموع السلف المخصومة» = اقتطاعات السلف في **مسيرات الشهر**، وليس إجمالي الأموال المسلفة سابقًا. جميع الإجماليات مفصولة حسب العملة.
- الترحيل لا ينشئ سجلات دوام ولا مدفوعات، ولا يمس الرواتب المعتمدة أو المصروفة سابقًا. يضع قيمة 0 فقط في *عداد الحضور الناقص* داخل مسودات الموظفين الشهريين القائمة؛ لا يغير أي حقل مالي.
- الاعتماد لا يدفع الراتب. بعد اعتماد المسير تصبح أزرار الدفع متاحة إذا كان هناك مبلغ متبقٍ وصندوق نشط.
- لا يُستخدم المسار الجديد لأجر يومي أو ساعي؛ دوالهم الأصلية وسجلاتهم التاريخية تبقى دون تغيير، لكن قسمهم أُخفي من واجهة مركز الدفع لعدم استعماله.

## اختبار قبل الاستخدام المالي
1. افتح مسودة مسير موجودة، وتأكد أن زر «اعتماد المسير» متاح دون تعبئة الدوام.
2. تأكد من أن رواتب الموظفين الشهرية لم تُخصم لأيام لا تحتوي سجلات حضور.
3. راجع موظفًا لديه سلفة وموظفًا لديه مكافأة وموظفًا لديه خصم يدوي. تأكد من إجمالياتهم.
4. اعتمد مسيرًا تجريبيًا، وتحقق أن الرصيد في الصندوق **لم يتغير** بالاعتماد.
5. ادفع مبلغًا اختباريًا في بيئة تطوير، وتأكد من أنه يظهر مرة واحدة في سجل الدفع وحركة الصندوق.
6. تأكد أن المسير المعتمد لا يتغير أو يعاد حسابه لاحقًا.

## حدود الاختبار
اختبارات JavaScript ثابتة ومحلية. لا يمكن تأكيد نجاح SQL أو الصرف على قاعدة بياناتك الحية حتى تشغله بنفسك، وممنوع إعادة تطبيق الدفعات الحقيقية فقط للاختبار.
