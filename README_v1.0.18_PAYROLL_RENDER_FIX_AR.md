# Maria CFO Web v1.0.18 — إصلاح توقف كشف الرواتب

## سبب الخلل
داخل `js/pages/payroll-v034.js` جرى حساب `monthlyMonth` داخل `paint()`، ولكن `readyHtml()` كانت تستعمله دون تمريره كوسيط، ما نتج عنه `ReferenceError: monthlyMonth is not defined` وتوقف عرض الجدول (مع بقاء إجماليات الأعلى).

## التغيير
- تمرير صفوف الموظفين الشهريين الموحّدة صراحةً من `paint()` إلى `readyHtml(monthlyMonth)`؛ وبالتالي تظهر إجماليات المكافآت والسلف والجدول دون خطأ نطاق المتغير.
- تحديث رقم الإصدار وروابط ملفات JavaScript المتغيرة لمنع بقاء نسخة الرواتب القديمة مخزنة في المتصفح.
- إضافة اختبار انحدار ينفّذ الرسم الفعلي ببيانات مسير شهري وتجربة التبويب والمدفوعات، وليس فحصًا نصيًا فقط.

## طريقة التثبيت
1. ارفع محتويات ZIP **كاملة** إلى الاستضافة، مع المحافظة على `config.js` الموجود لديك. لا تشارك إعدادات الربط ولا مفاتيح الخدمة.
2. حدّث المتصفح تحديثًا قويًا وتأكد من ظهور **Web v1.0.18**.
3. افتح مركز الدفع، وتحقق من عرض الموظفين وإجمالي المكافآت والسلف، ثم جرّب تبويب المدفوعات.
4. اعتمد المسير فقط بعد مراجعة مستحقات الشهر، ثم اختبر الدفع وفق الإجراء المالي المعتاد.

**لا يوجد SQL جديد في v1.0.18.** إذا لم تكن شغّلت ترحيل v1.0.17 الخاص بالحضور الافتراضي، فإنه يظل مطلوبًا لذلك السلوك، لكنه غير مرتبط بخطأ العرض هذا.

## حدود التحقق
جرى اختبار JavaScript محليًا ببيانات محاكاة دون الاتصال بقاعدة Supabase الحية أو تنفيذ اعتماد/دفع مالي حقيقي.
